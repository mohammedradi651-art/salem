# **App Name**: سالم العوبثاني - المنصة الرقمية

## Core Features:

- قسم الشخصية الرقمية (Hero Section): واجهة تفاعلية تضم صورة سالم، العنوان الوظيفي، ووصف المحتوى مع أزرار الانتقال المباشر للمنصات.
- لوحة الإحصائيات التفاعلية: عرض عدد المتابعين والمشاهدات والحملات الإعلانية في بطاقات متحركة وجذابة.
- ملخص المحتوى الذكي (AI Highlights): أداة Tool تستخدم الذكاء الاصطناعي لتصنيف وتلخيص أبرز محاور المحتوى الرقمي وسياق الفيديوهات الأخيرة تلقائياً.
- رابط التواصل الفوري: زر مباشر للتحويل لخدمة الواتساب عبر الرابط (wsend.co/967734252178) لتسهيل التعاون الإعلاني.
- موزاييك المنصات الاجتماعية: تصميم زجاجي (Glassmorphism) لبطاقات الربط مع تيك توك، سناب شات، يوتيوب، وإنستقرام (s.insta_x).
- غلاف الأداء العالي: هيكل معماري يعتمد على Next.js لضمان سرعة فائقة في التحميل وتجربة مستخدم فاخرة وسلسة.

## Style Guidelines:

- Primary color: Electric Glowing Blue (#00A3FF) representing tech and digital innovation.
- Background color: Deep Space Black (#06080B) to evoke a premium, luxury aesthetic.
- Accent color: Deep Indigo (#1A237E) to create a sophisticated, monochromatic-blue palette depth.
- Heading font: 'Poppins' for its geometric, high-end feel; Body font: 'Inter' for a machined, neutral and clean presentation.
- Ultra-thin linear icons with blue-cyan glow effects to match the digital creator identity.
- Single-page long-scrolling layout with centralized vertical flow designed for Mobile-First usability.
- Staggered fade-ins and subtle float effects on the statistics cards for an 'alive' feel.
